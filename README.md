# Nu Ayu Theme for Obsidian

Minimal theme focused on removing distractions and keeping it super clean and airy. Light mode inspired by Bear Notes Ayu implementatino, Dark mode created fully from scratch.

- Light & Dark modes
- Super clean minimal look
- Removed all the borders, hover highlights on hover and other stuff unnecessary for daily use
- Very nice looking Dark Mode created from scratch with full black backgrounds for mobile devices
- Special attention to mobile devices
- Meaningfull padding for Bases embeds on phone screens
